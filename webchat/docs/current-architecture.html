启动与检查

# 服务
brew services start postgresql@16
brew services start redis

# Web
python -m webchat --host 127.0.0.1 --port 8787

# Worker
WEBCHAT_QUEUE_URL=redis://127.0.0.1:6379/0 \
python -m webchat.worker

# 健康
curl http://127.0.0.1:8787/api/health
redis-cli ping
pg_isready -h 127.0.0.1 -p 5432

边界

  • PostgreSQL 是本机 Homebrew 单实例，不是高可用集群；
  • 知识库向量已切到 pgvector vector(256) + HNSW；
  • 中文 FTS 使用 ILIKE / pg_trgm 回退，不等价 SQLite FTS5 BM25；
  • Redis 是单实例，未配置密码/TLS；
  • 企业 SSO 尚未接入；
  • 多 Worker 尚未压测，任务不是 exactly-once。
