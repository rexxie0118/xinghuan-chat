MCP 连接池与分片

每个 MCP server 现在可以有多个独立 session：round-robin 分流， 单个 shard 失败自动 failover，并在 /api/tools 暴露 shards/calls/failures。

状态：已完成 测试：59 项通过 架构：v14

配置

{
  "servers": {
    "github": {
      "transport": "http",
      "urls": ["http://10.0.0.11:9000/mcp", "http://10.0.0.12:9000/mcp"],
      "shards": 2,
      "allow_tools": ["search_code"]
    }
  }
}
  • shards / pool_size：1-8；
  • HTTP 用 urls 指定不同分片地址；
  • stdio 同一配置启动多个子进程；
  • 工具发现取第一个健康 shard；
  • 调用按 round-robin，失败切换下一个。

验证

FakeClient round-robin
→ a:1
→ b:2

bad shard + good shard
→ failover to good
→ failures=1

59 tests passed

边界

  • 分片是可重试的独立 session；有副作用的工具仍可能重复执行。
  • 没有后台健康检查/自动重建，只在调用失败时切换。
  • 工具发现只取第一个健康 shard，不合并异构工具集。
