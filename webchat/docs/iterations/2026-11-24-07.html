Chat 模式联网开关

Chat 输入框新增「联网」开关：默认关闭；打开后 Chat 可以进入 Tool Loop， 调用已注册的连接器查询天气/新闻等实时信息。

状态：已完成 测试：64 项通过 架构：v18

变化

UI:
Chat + 联网（默认关）
→ request.live = true

backend:
if (mode == "agent" or live) and imported_agent is None:
    tool_loop()

Agent 模式仍然默认允许工具。

真实验证

Chat + live=true
问题：北京今天天气怎么样？
→ connector.weather_geocode
→ connector.weather_current
→ 北京当前天气：晴，0.3℃，湿度 28%

answer_mode=tool_loop
tool_steps=2

边界

  • 联网开关只在 Chat 模式显示；Agent 模式默认有工具。
  • 没有连接器时，live 仍会回退普通 RAG。
  • 外部来源还没有统一引用面板，当前在回答正文中给出来源。
