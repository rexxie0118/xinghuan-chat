安装过程中遇到的问题

  • Docker Hub 拉取 python 镜像连接超时，改用 mirror.gcr.io/library/python:3.12-slim，再打本地 tag。
  • 第一次误装了 vmlinuz，VM 启动失败；Apple Container 推荐的内核是 vmlinux-*-debug，替换后正常。
  • Kata 归档约 645MB，普通下载多次中断；最终用并行 Range 下载并校验 SHA-256。
  • Apple Container 目前没有 --network none，默认使用 default 网络；无网需要宿主机防火墙。
