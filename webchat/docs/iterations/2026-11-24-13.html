Apple Container 网络与安全策略

APPLE_CONTAINER_NETWORK 支持 isolated / none：映射到 host-only xh-isolated 网络，阻止容器访问公网；default 才允许外网。

状态：已完成 测试：77 项通过 架构：v24

策略

APPLE_CONTAINER_NETWORK=isolated
→ network_policy → xh-isolated
→ container network create --internal
→ --network xh-isolated
→ 无 DNS / 无公网

APPLE_CONTAINER_NETWORK=default
→ 允许外网（显式）

真实验证

container run --network xh-isolated ... python urllib
→ URLError: Temporary failure in name resolution
→ 隔离网络阻止访问公网

77 tests passed

其他边界

  • 一次性 runner 仍使用 --read-only、--cap-drop ALL、tmpfs；
  • pool 容器同样继承网络策略；
  • host-only 网络仍允许宿主控制面生命周期，不是完全 air-gap；
  • 需要联网的 Agent 必须显式配置 default 或自定义网络。
