边界

  • 只用于默认本地 Agent；导入 Agent / 外部 Agent 保持原链路。
  • 需要真实 LLM + 至少一个 ToolRegistry 工具；无工具时保持原 RAG。
  • max_steps 默认 4；达到上限或 LLM 失败回退知识库。
  • 工具调用目前同步执行，尚未做并行 tool calls。
  • 工具结果截断到 6000 字符回填。
