Apple Container 常驻运行时管理器

新增 AppleContainerRuntime：用确定性 key 管理常驻容器与 named volume， 支持 ensure / start / stop / delete / list，为 per-user、per-session 容器铺路。

状态：已完成 测试：28 项通过 + 真机生命周期冒烟 架构：v3

确定性命名

key → xh-rt-<hash> / xh-vol-<hash>，避免用户/会话 ID 直接进入容器名。

names_for(key)
DONE

容器生命周期

ensure 自动创建 volume、create、start；stop / delete 可恢复或清理。

ensure/start/stop/delete
DONE

托管发现

通过 xh.managed / xh.key / xh.volume labels 列出受管容器。

list_managed()

真机冒烟

ensure('smoke-user')
→ xh-rt-9bbf17488ebfc5c9 · running
→ xh-vol-9bbf17488ebfc5c9

stop('smoke-user')
→ stopped

ensure('smoke-user')
→ running

delete('smoke-user', delete_volume=True)
→ container + volume cleaned

边界

  • 管理器只负责容器/volume，不负责用户会话状态和 idle 策略。
  • 已有 app.state.container_runtime，但还没有接入聊天路径。
  • Apple Container 的 --network none 仍不可用，默认网络需要宿主侧策略。
  • per-user / per-session 映射、预热池、checkpoint 恢复仍是待办。
