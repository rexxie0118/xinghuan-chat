MCP 权限与安全

MCP server 增加 trusted / deny_tools / allow_dangerous / allow_hosts / env_allowlist；危险工具默认关闭，HTTP host 和环境变量扩展受边界限制。

状态：已完成 测试：75 项通过 架构：v23

安全字段

trusted: true
allow_tools: ["read_file"]
deny_tools: ["write_file"]
allow_dangerous: false
allow_hosts: ["example.com"]
env_allowlist: ["MCP_TOKEN"]

强制点

  • untrusted server 不加载；
  • deny_tools 优先于 allow_tools；
  • dangerous=true + allow_dangerous=false → 调用拒绝；
  • HTTP host 必须在 allow_hosts；
  • ${ENV} 只展开 env_allowlist 中的变量；
  • 工具调用记录 duration 和参数 key，不记录敏感值。

边界

  • MCP 配置文件本身是可信管理员输入；
  • stdio server 仍是本机进程，不是沙箱；
  • 没有交互式审批队列，dangerous 采用显式配置放行；
  • MCP server 的输出仍视为不可信数据。
