关键决策

  • 不重写成 Pi：借鉴 extension 的 hook 设计，但保留 FastAPI + Python + 多用户产品壳。
  • 插件先做可信内部插件：运行在 Web 进程内；租户代码不允许 in-process。
  • 不可信执行外置：MCP 是外部工具边界，Apple Container 是不可信脚本边界。
  • 当前不是高并发架构：单进程、SQLite、同步 LLM/MCP/Container；已在 todo 中拆队列/Worker。
