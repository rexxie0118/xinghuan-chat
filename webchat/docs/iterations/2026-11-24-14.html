外部 Agent 接 MCP/ReAct

外部 Agent 的 /chat 契约支持 tool_calls：Web 执行本地 MCP/plugin/connector 工具，把 observations 回传，最多 4 步；旧 answer 契约仍兼容。

状态：已完成 测试：79 项通过 架构：v25

协议

Web → external /chat
{
  react: true,
  tools: [...],
  observations: [...],
  messages: [...],
  context: {...}
}

external → Web
{ tool_calls: [...] }
→ ToolRegistry.call
→ observations
→ /chat again

external → Web
{ answer: "...", citations: [...] }

安全

  • 外部 Agent 不能执行本地代码；
  • 只能请求 ToolRegistry 中存在的工具；
  • 危险工具仍受 MCP/plugin 权限边界；
  • 工具调用有超时、错误和取消检查。

验证

fake external:
tool_calls demo.echo → echo:hi
answer 使用工具后回答
tools_used=["demo.echo"]
steps=2

legacy answer 仍通过
