知识库文档管理 UI

顶部新增「知识库文档」：选择知识库、上传文档、查看分块数、删除源文件、 强制重建索引；admin/manager 可写，member 只读。

状态：已完成 测试：87 项通过 架构：v31

UI

知识库文档
选择 KB
上传 .md/.txt/.rst/.pdf/.docx
列表：标题 / 文件 / 类型 / 分块 / 更新时间
删除 → 源文件 + 索引
重建索引

API

GET    /api/kb/documents?kb=product
POST   /api/kb/documents?kb=product
DELETE /api/kb/documents/{id}?kb=product
POST   /api/kb/reindex?kb=product

验证

admin 上传 kb-docs-test.md
→ documents 包含该文档
→ DELETE 后列表移除
→ 源文件删除
87 tests passed

边界

  • 单文件 10MB；
  • PDF/DOCX 依赖未默认安装；
  • 扫描 PDF 无 OCR；
  • 没有批量上传/拖拽排序；
  • 删除不保留历史版本。
