行为

  • 队列满 → HTTP 429，客户端退避后重试；
  • 排队超时 → HTTP 429；
  • 运行超时 → token 取消，worker 保存 cancelled 消息；
  • 客户端断开 → worker 继续保存，lease 在 worker 结束释放；
  • /api/meta.concurrency 暴露 active / waiting / limits。

边界

  • 这是单进程内的并发控制，不是跨节点队列。
  • asyncio.to_thread 线程无法被强制杀死，超时是协作式取消。
  • 多 Worker / Postgres / Redis 队列仍在后续 Todo。
