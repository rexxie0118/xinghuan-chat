记忆 UI 入口修复

修复点击「记忆」没有打开弹窗：给静态资源加版本号避免旧 app.js 缓存， 并把入口改为 document 级事件委托，避免前序绑定异常导致按钮失联。

状态：已完成 测试：50 项通过 架构：沿用 v11

问题

  • 页面 HTML 已更新，但浏览器可能继续使用旧 app.js。
  • 旧脚本没有 #memory-btn 监听，点击看起来无响应。
  • 入口绑定位于 bindEvents() 末尾，前序绑定异常会连带失效。

修复

styles.css?v=20261123-memory
app.js?v=20261123-memory

document.addEventListener("click", (event) => {
  if (!event.target.closest("#memory-btn")) return;
  event.preventDefault();
  openMemoryManager();
});

保留直接入口逻辑，但改用委托后不再依赖 bindEvents 走到最后一行。

GET /static/app.js 包含 openMemoryManager
GET /static/app.js?v=20261123-memory 返回最新文件
50 tests passed
