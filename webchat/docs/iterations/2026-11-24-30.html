Redis 实例与异步 Worker 队列

安装并启动 Redis 8.12.0，配置 WEBCHAT_QUEUE_URL；Web 入队、Worker 消费， 真实完成一次 queued → completed 的 RAG job；修复 BRPOP socket timeout 竞态。

状态：已完成 测试：116 项通过 架构：v41

实例

Redis 8.12.0
127.0.0.1:6379
brew services start redis
redis-cli ping → PONG

WEBCHAT_QUEUE_URL=redis://127.0.0.1:6379/0

链路

Web API
→ POST /api/jobs/agent/{conversation}
→ Redis list webchat:jobs:ready
→ Worker BRPOP
→ AgentRunner
→ Postgres message/result
→ GET /api/jobs/{id} completed

Redis 8.12 + redis-py 8.2
BRPOP timeout race → 已修复

修复

  • dequeue 捕获 Redis TimeoutError/ConnectionError，按空闲轮询处理；
  • 显式 socket_connect_timeout=5；
  • Worker 不再因一次 BRPOP 超时退出。

边界

  • 没有 retry / DLQ；
  • 没有 running lease 回收；
  • Worker 崩溃时 running job 不会自动重派；
  • 单 Worker 已验证，多 Worker 未压测；
  • Redis 是任务协调层，不是持久事实库。
