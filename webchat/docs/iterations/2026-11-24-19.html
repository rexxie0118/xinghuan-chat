用户权限管理界面

顶部新增 admin-only「用户权限」：列出用户，直接修改部门/角色并保存； demo 提供 admin 账号，用户下一次请求按新 RBAC 生效。

状态：已完成 测试：86 项通过 架构：v30

UI

Topbar → 用户权限（仅 admin）
用户列表
  部门 select
  角色 select（member / manager / admin）
  保存 → PATCH /api/admin/users/{id}

账号

admin / admin1234（demo 管理员）
demo  / demo1234  （产品部 member）

边界

  • 没有删除用户；
  • 没有保护“最后一个 admin”；
  • 没有批量修改和审计 UI；
  • 修改后用户下一次请求生效。
