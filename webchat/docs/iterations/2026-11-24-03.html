边界

  • 当前预热池管理容器生命周期；一次性 Agent runner 仍使用 disposable container。
  • 没有 idle TTL 自动缩容；池在进程退出时整体清理。
  • owner 配额以 RunRequest owner 为准，迁移 Agent 执行时才完全生效。
  • 预热容器不是 per-user workspace；workspace 映射仍在独立表中。
