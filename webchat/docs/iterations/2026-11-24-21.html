PPTX / Excel 解析依赖与入库

安装 python-pptx / openpyxl / xlrd，并接入 kb parsers；知识库上传现支持 .pptx / .xlsx / .xlsm / .xls，PPT 按页、Excel 按工作表转文本。

状态：已完成 测试：90 项通过 架构：v32

依赖

python-pptx 1.0.2
openpyxl    3.1.5
xlrd        2.0.2
pillow      13.0.0

解析

PPTX
  ## 第 N 页
  文本框 / 表格 / 备注

Excel
  ## 工作表：名称
  Markdown 表格
  最多 2000 行 / 60 列

验证

PPTX 标题、表格、备注提取通过
XLSX 工作表行数据提取通过
90 tests passed

边界

  • 图片型 PPT / 扫描 PDF 不做 OCR；
  • Excel 仅提取值，不保留样式和公式；
  • 超过 2000 行会截断；
  • .xls 旧格式依赖 xlrd，复杂宏文件不保证。
