运行方式

pip install -r requirements-infra.txt

WEBCHAT_DB_URL=postgresql://...
WEBCHAT_QUEUE_URL=redis://...
WEBCHAT_OBJECT_STORE=s3

python -m webchat
python -m webchat.worker

# 或
docker compose up

边界

  • 普通聊天 SSE 仍在 Web 进程内执行；queued agent_run 走独立 Worker。
  • 知识库检索 SQLite 文件暂未迁移到 Postgres。
  • Redis job 目前没有重试/死信队列；Worker 崩溃后 job 可能停在 running。
  • S3 适配需要 boto3 和可用 bucket；本地默认仍是 local。
  • Docker Compose 中的密码是示例值，生产必须替换。
