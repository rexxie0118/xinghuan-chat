排序规则

version key:
  1. 正文/元数据里的生效日期
  2. 没有日期 → 文件 mtime 月份
  3. 生效月相同 → 文件 mtime 决胜

同族多版本:
  默认只保留最新版本

历史查询:
  "旧版 / 历史 / 对比 / 变化"
  → 保留所有版本

不同主题:
  年假制度 ≠ 报销制度
  → 不互相过滤

边界

  • 文件名没有版本标记、内容也没有日期时，无法可靠判断新旧；
  • 文件 mtime 会被复制/重新上传改变，因此只做兜底；
  • 政策类文档仍额外享受“制度优先于通用 FAQ”的排序；
  • 产品库误传的旧版年假制度仍需单独删除。
