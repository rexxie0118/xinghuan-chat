可观测性与审计

新增 X-Request-ID、audit_events、/api/audit、/api/metrics；API、chat run 和工具调用都写入结构化审计，不保存 prompt、输出、参数值或 secret。

状态：已完成 测试：83 项通过 架构：v27

审计事件

api_request  method/path/status/duration
chat_run     mode/answer_mode/tools/run_id
tool_call    tool/server/duration/failure

关联

  • 响应头 X-Request-ID；
  • request_id 通过 contextvar 进入 chat/tool；
  • user_id 由登录依赖写入；
  • conversation_id / run_id 在 chat_run 中关联。

API

GET /api/audit?limit=50&event_type=tool_call
GET /api/metrics

metrics:
  events / errors / error_rate
  avg_duration_ms / max_duration_ms
  by_type / by_component / failures

边界

  • 审计不是完整分布式 tracing；
  • metrics 基于最近 500 条事件，不是 Prometheus；
  • 没有审计导出/保留策略 UI；
  • metadata 仍可能包含错误文本，需要继续脱敏。
