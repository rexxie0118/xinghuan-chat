声明式联网连接器

新增 Connector Factory：已知 catalog、声明式 HTTP spec、host/参数/auth 校验、 测试请求、审批，以及注册到 ToolRegistry 的 connector.<name> 工具。

状态：已完成 测试：64 项通过 架构：v16

流程

需求
→ GET /api/connectors/catalog
→ POST /api/connectors/propose
→ POST /api/connectors              （draft）
→ POST /api/connectors/{id}/test
→ POST /api/connectors/{id}/approve
→ connector. 进入 Tool Loop

安全约束

  • 只允许 HTTPS；
  • allow_hosts 必须包含目标 host；
  • 只允许 GET / POST；
  • 不生成任意 Python 代码；
  • auth 只引用环境变量，不把 secret 写进 spec；
  • 响应最大 256KB；
  • 审批前不注册工具。

内置 catalog

weather_geocode   Open-Meteo Geocoding
weather_current   Open-Meteo current weather

→ 两个工具可被 LLM 串联：
   city → lat/lon → current weather

边界

  • spec 由规则或 LLM 生成，但必须通过 validation；
  • test 是受控 HTTP 请求，不是完整 Apple Container 沙箱；
  • 没有连接器管理 UI，当前通过 API 操作；
  • 复杂 OAuth / 签名 / 分页 API 仍建议做成 MCP server。
