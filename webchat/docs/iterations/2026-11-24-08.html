Web Research 工具链

新增 web.search / web.fetch / web.research：搜索、抓取、来源评分和冲突检测； Chat 联网开关与 Agent Tool Loop 都可以调用。

状态：已完成 测试：69 项通过 架构：v19

工具

web.search
  → Tavily / SearXNG
web.fetch
  → HTTPS only · SSRF guard · 512KB
web.research
  → search + fetch top N
  → source_rank
  → conflict_detect
  → sources + conflicts

来源评分

  • 官方 / gov / edu / 原始文档优先；
  • 可信媒体次之；
  • 普通网页再次；
  • 低质量域名降权；
  • 结合发布时间、搜索分数、同域多结果。

冲突检测

对同主题、不同数字的句子标记冲突，返回 details；回答层应展示分歧，而不是合并成一个确定结论。

配置

TAVILY_API_KEY=...
# 或
WEBCHAT_SEARXNG_URL=http://127.0.0.1:8888
WEBCHAT_WEB_ALLOW_HOSTS=

边界

  • 没有 API key / SearXNG 时搜索工具返回配置错误；
  • 冲突检测是启发式，不替代人工事实核查；
  • 搜索结果正文和发布时间依赖页面质量；
  • 外部来源引用还没有独立 UI 面板。
