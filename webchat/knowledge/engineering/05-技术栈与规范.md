# 技术栈与研发规范

## 一句话回答

研发团队的后端以 Python 和 Go 为主，前端使用 React 与 TypeScript，数据层使用 PostgreSQL、Redis 和 Kafka。

## 服务端

核心服务使用 Python FastAPI 和 Go。Python 适合知识库、检索和 Agent 服务，Go 适合高并发的网关与订单链路。所有服务通过 OpenAPI 描述接口。

## 前端

管理后台和对话产品使用 React、TypeScript 与 Vite。组件库统一使用内部设计系统，不允许直接引入未审核的第三方 UI 框架。

## 数据层

系统用到的数据库包括 PostgreSQL、Redis 和 TiDB，Kafka 用于异步消息。

- PostgreSQL 存储业务元数据和权限数据。
- Redis 做会话缓存和限流。
- Kafka 承载异步事件与通知。
- 对象存储保存文档原件和构建产物。

## 研发规范

代码合并前必须通过单元测试和静态检查。核心模块的测试覆盖率不得低于 70%。接口变更需要同步更新 OpenAPI 文档，并在变更单里说明兼容性。

## 相关系统

统一登录服务 使用 Redis 做会话缓存，依赖 PostgreSQL 存放账号数据。订单中心 使用 Kafka 发送订单事件。知识库服务 使用 对象存储 保存原始文档。
