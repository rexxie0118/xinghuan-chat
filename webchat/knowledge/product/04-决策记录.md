# 决策记录

## ADR-001 用 TiDB 替代 MySQL

订单中心 在 2026-04 遇到单表容量瓶颈，我们决定用 TiDB 替代 MySQL。迁移在 2026-05 完成，写入延迟下降 40%。
这是一个不可逆决策，回滚成本很高。

## ADR-002 放弃自建消息队列

团队曾评估自建消息队列，最终决定放弃，改用 Kafka。原因是运维成本高于收益。
支付网关 的异步通知由此统一走 Kafka。

## ADR-003 统一登录从 Session 迁移到 JWT

统一登录服务 在 2026-06 迁移到 JWT，以支持多端登录。旧的 Session 方案保留到 2026-12。
