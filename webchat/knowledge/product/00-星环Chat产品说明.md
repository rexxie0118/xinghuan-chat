# 星环 Chat 产品说明

星环 Chat 是一个面向团队的 AI 对话工作台，把多用户会话、RAG 检索与本体图谱放进同一个界面。

## 核心能力

星环 Chat 支持多用户会话、RAG 引用、Agent 工具轨迹、本体图谱和多部门知识库切换。

- 会话历史持久化：每个账号拥有独立的会话列表，消息写入 SQLite，刷新或重新登录后仍然保留。
- 双引擎问答：RAG 模式直接检索知识库；Agent 模式会先检索、再扩展图谱邻域、最后组合作答，并在界面展示工具轨迹。
- 知识库面板：右侧可以查看混合检索召回的引用、实体关系图和文档清单。
- 多部门知识库：知识库按部门授权，用户可以在自己的部门知识库和公司公共知识库之间切换。会话和消息按用户隔离。
- 外部 Agent：星环 Chat 可以通过 HTTP 调用另一个仓库里的 Agent 服务，不把 Agent 代码耦合进前端应用。

## 使用建议

打开左侧会话列表可以新建、重命名或删除对话；右侧面板可以查看本次回答的引用、实体关系图和已摄取文档。Agent 模式会在回答上方展开工具轨迹，适合演示 RAG 之外的本体推理步骤。
