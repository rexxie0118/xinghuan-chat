# 术语表

## 一句话回答

RAG 是检索增强生成，Ontology 是本体图谱，Agent 是能调用工具完成多步任务的智能体。

## 核心术语

- RAG：Retrieval-Augmented Generation，先从知识库检索证据，再让模型基于证据回答。
- Ontology：本体图谱，用实体、类型和关系描述业务知识的结构。
- Agent：能规划步骤、调用工具并根据结果继续推理的智能体。
- Embedding：把文本转换成向量，用于语义相似度检索。
- RRF：Reciprocal Rank Fusion，把多路召回结果按排名融合。
- P1：最高优先级的线上事故。
- KPI：关键绩效指标。

## 使用约定

在星环 Chat 里，RAG 模式 使用 混合检索 和 引用。Agent 模式 额外 使用 本体图谱 和 工具轨迹。知识库 由 文档、分块、实体 和 关系 组成。

## 相关服务

知识库服务 包含 检索服务 和 本体图谱服务。Agent 服务 使用 工具服务，Agent 服务 依赖 知识库服务。
