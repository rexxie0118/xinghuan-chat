# 星图科技公司简介

## 一句话回答

星图科技是一家面向企业客户的知识管理与智能协作公司，核心产品是星环 Chat 和北极星知识库。

## 公司业务

公司的主要业务是企业知识库、智能问答和 Agent 工作台，客户来自制造、金融和互联网行业。

星图科技成立于 2021 年，总部在杭州，在北京和深圳设有办公室。公司为制造、金融和互联网客户提供企业知识库、智能问答和 Agent 工作台。

## 组织架构

公司下设产品部、研发部、人事部和商业化团队。产品部负责北极星项目和星环 Chat 的产品定义，研发部负责平台与 Agent 基础设施，人事部负责招聘、绩效和员工服务。
